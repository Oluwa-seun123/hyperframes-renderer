# MÁADÁN — A Ritual of Your Own
**ASO Creative Studio | 90-second vertical spec-ad test | 1080 × 1920 | 30 fps | silent master**

> **Speculative concept only.** This is an independent portfolio/test concept, not an official MÁADÁN commission or endorsement. Confirm permission before using the brand's name, marks, or product packaging in a public commercial campaign.

## Why this product
MÁADÁN describes itself as an African botanical skincare brand handmade in Lagos, Nigeria. Its official site lists body butter among its products. This makes it a strong test subject for a visually rich, locally grounded story about self-care, texture, and ritual. Research links are listed at the end.

## Creative direction
**Campaign line:** “A ritual of your own.”
**Audience:** Adults who want their daily body-care routine to feel considered and premium.
**Tone:** Quiet luxury, tactile macro imagery, warm skin tones, botanical shadows, deep cocoa, amber and cream.
**Format:** 9:16 social-first master. Designed to work without audio; voiceover and music can be added in a separate editor.
**Narrative:** Move from the noise of the day into a personal pause, then build a sensory product reveal and a restrained call to action.

## What this first pass actually contains
- A 90-second HTML/CSS/GSAP motion-design composition.
- Ten timed visual chapters with typography, layered gradients, animated botanical motifs, and a stylised product-pack shot.
- No audio track, voiceover, or music, by design.
- No downloaded third-party photography. The pack shot is an illustrative stand-in, **not a verified replica of the real product packaging**.
- A shot-by-shot production / voiceover timing guide in `production-notes.md`.

## Important production caveats
This is a motion-graphics prototype, not yet a full live-action commercial. The visuals are original CSS/vector-style artwork. For a client-ready film, replace the stylised pack shot with approved product photography, add licensed/generated macro footage, verify product copy and ingredients against the current packaging, and obtain brand approval. Do not make medical or guaranteed skin-result claims.

## Run locally
From this folder, with Node.js installed and internet access for the Hyperframes CLI:

```bash
npm run dev
npm run check
npm run snapshot
npm run render
```

The commands are configured but **have not been executed in this environment**. Rendering success is not yet verified. Check CLI output and inspect the resulting MP4 before delivery.
