HYPERFRAMES · PHASE 8

HFX HyperFrames Exporter

Compile your real 3D product model and HFX shot plan into a fixed-size, seekable HTML composition that the HyperFrames renderer can capture frame-by-frame.

01 · Source assets

Choose the GLB model and the shot-plan JSON from Phase 7. Both are processed locally in this browser.

02 · What the exporter creates

1
Embeds the 3D model
The GLB bytes are embedded in the exported HTML so the composition does not depend on a separate model file.
2
Compiles a deterministic timeline
Shot durations, camera moves, object turntable, labels, transitions and frame rate are compiled into a seekable GSAP timeline.
3
Prepares a HyperFrames composition
Fixed output dimensions, composition timing and window.__timelines.main are included for frame-by-frame rendering.

03 · Render hand-off

The exported HTML is an intermediate HyperFrames composition. Place it at image-motion-studio/project/index.html in the repository and run the existing HyperFrames check/render workflow. The exporter does not itself run the GitHub render job or claim an MP4 has been produced.
