# Phase 14 — Asset Quality Gate

A browser-only image inspector that checks source image dimensions, aspect ratio, file size, exact duplicates (SHA-256), and creates a JSON QC report.

## Limitations
It does not evaluate product authenticity, licence, artistic quality, composition, blur, visual similarity beyond exact duplicates, or infer missing product views. Thresholds are simple heuristics and are not universal quality standards.

All processing is local in the browser; nothing is uploaded.
