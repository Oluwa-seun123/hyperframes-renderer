# Phase 15 — Campaign Handoff Pack

Browser-only storyboard and campaign handoff utility:
- Multi-image import with embedded data URLs
- Reorder shots by move up/down
- Shot notes and campaign brief
- JSON export with all images embedded, ready for manual transfer into the renderer workflow

## Limitations
- Exported JSON can be large due to embedded full-resolution images.
- No MP4 rendering, ZIP creation, cloud sync, background removal or automatic GitHub upload.
- No auto-generated shot recommendations; notes are entered by the producer.
- Runs locally in the browser.
